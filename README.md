# Java-OOP-Assignment-Bank-Account-Management-System

A simple Java program that implements a Bank Account Management System using **classes and objects**.

### Features
- Create two bank accounts.
- Deposit and withdraw money.
- Check account balance.
- Display account details.
- Maintain independent balances for each account.

### Concepts Used
- Classes and Objects
- Parameterized Constructor
- Methods
- Encapsulation Basics

### How to Run
```bash
javac Main.java
java Main
```
